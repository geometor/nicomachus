=======
Modules
=======

The ``geometor.nicomachus`` Python package provides exact symbolic ``SymPy`` and ``geometor.model`` formalizations of Nicomachus of Gerasa's *Introductio Arithmetica* (Books I–II), covering the Quadrivium, ratio unfolding trees from equality, arithmetic gnomons, polygonal and pyramidal numbers, and the complete ten Pythagorean musical means.

CLI Summary
-----------

.. code-block:: bash

   python -m geometor.nicomachus
