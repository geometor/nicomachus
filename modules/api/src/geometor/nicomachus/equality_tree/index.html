src.geometor.nicomachus.equality_tree¶

Nicomachus’s Rule of Three Terms & Reduction to Equality (Book I, Chs. 17–23; Book II, Chs. 1–2).

Formalizes Nicomachus of Gerasa’s foundational theorem of Pythagorean arithmetic philosophy: Equality (\(1 : 1 : 1\)) is the primordial mother and root (μήτηρ καὶ ῥίζα) of all five species of relative inequality (πολλαπλάσιος, ἐπιμόριος, ἐπιμερής, πολλαπλασιεπιμόριος, πολλαπλασιεπιμερής), and every geometric triple reduces back to Equality by finite Euclidean subtraction.

Algebraically, Nicomachus’s three-term unfolding rule

\[(a, b, c) \longmapsto (a,\; a + b,\; a + 2b + c)\]

is the unimodular matrix \(N_1 \in \mathrm{SL}_3(\mathbb{Z})\) acting on the second symmetric Veronese cone \(a c = b^2\), while his reversed (ἀναστρέψαντι) sibling rule is \(N_2 = N_1 R\). Together \((N_1, N_2)\) generate a bijection from \((1, 1, 1)\) onto all primitive integer geometric progressions \((u^2, u v, v^2)\) with \(1 \le u < v\) and \(\gcd(u, v) = 1\).

class src.geometor.nicomachus.equality_tree.EqualityNode¶

Single node in Nicomachus’s binary unfolding tree from Equality (1, 1, 1).

Variables:

  • terms – Exact ascending geometric triple (a, b, c) with a * c == b**2.

  • root_pair – Coprime positive integer root pair (u, v) such that terms == (u**2, u * v, v**2).

  • ratio – Common geometric ratio sp.Rational(v, u).

  • species_key – Canonical Nicomachean species identifier ("equality", "multiplex", "superparticularis", "superpartiens", "multiplex_superparticularis", or "multiplex_superpartiens").

  • greek_species – Greek technical name from Nicomachus I.17–22.

  • latin_species – Boethian Latin technical name (De Inst. Arith. I.22–28).

  • path – Sequence of "N1" (direct) and "N2" (anastrophe) rule applications from (1, 1, 1).

  • depth – Tree depth (0 at (1, 1, 1)).

class src.geometor.nicomachus.equality_tree.ReductionStep¶

Single inverse subtraction step in Nicomachus’s Book II, Chs. 1–2 algorithm.

Variables:

  • step_index – 1-based step index along the reduction back to Equality.

  • before – Ascending geometric triple (a, b, c) entering this step.

  • raw_subtracted – Raw triple N1^-1 * before = (a, b - a, a - 2*b + c) prior to optional reversal.

  • reversed_order – True if raw_subtracted had descending order and was reversed via R to restore ascending order (undoing an N2 step).

  • after – Resulting ascending triple (a', b', c').

  • undone_rule – "N2" when reversed_order is True, else "N1".

src.geometor.nicomachus.equality_tree.generate_equality_tree(max_depth: int = 3) → list[EqualityNode]¶

Generate Nicomachus’s binary unfolding tree up to max_depth from (1, 1, 1).

At the root (1, 1, 1), N1 and N2 coincide (since R * (1, 1, 1) = (1, 1, 1)), producing the first multiple (1, 2, 4) at depth 1. From depth 1 onward, each node branches cleanly into its direct N1 child and its reversed (anastrophe) N2 child without duplicates.

Parameters:

max_depth – Non-negative maximum depth of rule applications (default 3).

Returns:

Breadth-first list of EqualityNode instances from depth 0 to max_depth.

Raises:

ValueError – If max_depth < 0.

src.geometor.nicomachus.equality_tree.unfold_five_species_from_equality() → dict[str, EqualityNode]¶

Exhibit Nicomachus’s canonical derivation of all five species of inequality (I.23).

Follows Hoche pp. 64–70 step-by-step:

  1. Equality: (1, 1, 1) (ratio 1:1)

  2. Multiplex: N1(1, 1, 1) = (1, 2, 4) (duple 2:1)

  3. Superparticularis: N2(1, 2, 4) = (4, 6, 9) (hemiolios 3:2)

  4. Multiplex superparticularis: N1(4, 6, 9) = (4, 10, 25) (5:2)

  5. Superpartiens: N2(4, 6, 9) = (9, 15, 25) (epidimoiros 5:3)

  6. Multiplex superpartiens: N1(9, 15, 25) = (9, 24, 64) (8:3)

Returns:

Mapping from canonical species key to its EqualityNode witness.

src.geometor.nicomachus.equality_tree.reduce_to_equality(a: int | sympy.Integer, b: int | sympy.Integer, c: int | sympy.Integer) → list[ReductionStep]¶

Reduce any positive geometric triple (a, b, c) back to Equality (II.1–2).

Applies Nicomachus’s inverse subtraction matrix NICOMACHUS_INVERSE_MATRIX (\(N_1^{-1}\)) iteratively, reversing descending intermediate triples via REVERSAL_MATRIX_R until (g, g, g) is reached ((1, 1, 1) for primitive triples).

Parameters:

  • a – First positive integer term of the geometric progression.

  • b – Mean positive integer term satisfying b**2 == a * c.

  • c – Third positive integer term of the geometric progression.

Returns:

Chronological list of ReductionStep records ending at Equality.

Raises:

ValueError – If (a, b, c) are non-positive or not in geometric progression.

src.geometor.nicomachus.equality_tree.construct_equality_ray_model() → geometor.model.Model¶

Build an exact Model of Nicomachus’s five-species ratio rays.

Constructs the root lattice (u, v) of coprime geometric triples (u^2, u v, v^2) with auto_intersect=False, cuts every species ray against the unit gauge line x = 1 via intersect(), and verifies the exact rational cross-sections 1, 3/2, 5/3, 2, 5/2, 8/3, 3.

Returns:

Verified exact symbolic Model.
