geometor.nicomachus.figurate_gnomons¶

Sieve, Perfect Numbers, Polygonal Gnomons & Nicomachus’s Cubes Theorem (Book I.13–16; Book II.6–20).

Formalizes Nicomachus of Gerasa’s theory of absolute number (καθ’ ἑαυτὸ ποσόν) and figurate geometry of arithmetic:

  • Sieve of Eratosthenes (κόσκινον Ἐρατοσθένους, I.13): Sieving the odd progression \(3, 5, 7, 9, \dots\) by arithmetic strides to separate prime & incomposite numbers from secondary & composite numbers.

  • Abundant, Deficient & Perfect Numbers (I.14–16): Classification by aliquot sum \(\sigma'(n)\) and the Euclid–Nicomachus generation of \(6, 28, 496, 8128\).

  • Polygonal Numbers & Gnomons (II.7–12): Exact arithmetic gnomons \(g(s, k) = 1 + (s - 2)(k - 1)\), polygonal numbers \(P(s, n)\), triangular decomposition \(P(s, n) = T_n + (s - 3) T_{n-1}\), and planar Model constructions over \(\mathbb{Q}\) and \(\mathbb{Q}(\sqrt{3})\).

  • Same & Other — Squares vs. Heteromecic Numbers (II.17–19): Odd gnomons summing to \(n^2\) (ταὐτόν, Same) vs. even gnomons summing to \(n(n + 1)\) (θάτερον, Other).

  • Pyramidal Numbers & Nicomachus’s Sum-of-Cubes Theorem (II.13–16, II.20): Odd blocks of length \(k\) summing to \(k^3\) and L-gnomon square dissection proving \(\sum_{k=1}^n k^3 = T_n^2\).

geometor.nicomachus.figurate_gnomons.sieve_of_eratosthenes(limit: int = 100) → dict[str, Any]¶

Execute Nicomachus’s odd-number koskinon of Eratosthenes up to limit (I.13).

Nicomachus sets out the odd integers \(3, 5, 7, 9, \dots\) (treating the dyad 2 as the principle of the even rather than an odd prime) and marks composite odd numbers by striding p places among the odds (i.e. step 2*p in integer value) from each unmarked prime p.

Parameters:

limit – Upper integer bound >= 3.

Returns:

Dictionary containing odd_sequence, odd_primes, all_primes (including 2), odd_composites, and witness_factors mapping each composite odd to the ordered tuple of sieving primes that strike it.

Raises:

ValueError – If limit < 3.

geometor.nicomachus.figurate_gnomons.euclid_nicomachus_perfect_numbers(count: int = 4) → list[dict[str, Any]]¶

Generate the first count Euclid–Nicomachus even perfect numbers (I.16; Elem. IX.36).

Accumulates dyadic powers \(1 + 2 + 4 + \dots + 2^{p-1} = 2^p - 1\); whenever the sum is prime, multiplies it by the final dyadic term \(2^{p-1}\) to yield \(P = 2^{p-1}(2^p - 1)\). For count = 4, yields Nicomachus’s canonical tetrad 6, 28, 496, 8128 across units, tens, hundreds, and thousands.

Parameters:

count – Number of even perfect numbers to generate (1 <= count <= 7).

Returns:

List of dictionaries detailing exponent, mersenne_prime, last_dyadic_term, perfect_number, and verified aliquot_sum.

Raises:

ValueError – If count < 1 or count > 7.

geometor.nicomachus.figurate_gnomons.construct_polygonal_gnomon_model(sides: int = 4, order: int = 4) → PolygonalGnomonResult¶

Build an exact Model of sides-gonal gnomon shells.

Supports triangular (3), square (4), pentagonal (5), hexagonal (6), and heptagonal (7) lattices with auto_intersect=False. For sides == 4 uses the Gaussian integer lattice \(\mathbb{Q}^2\); for sides in {3, 5, 6, 7} uses Nicomachus’s Book II, Ch. 12 decomposition into (sides - 2) equilateral triangular sectors in \(\mathbb{Q}(\sqrt{3})\) so every shell step has exact unit quadrance.

Parameters:

  • sides – Number of polygon sides (3 <= sides <= 7).

  • order – Number of gnomon shells to construct (1 <= order <= 6).

Returns:

Verified PolygonalGnomonResult.

Raises:

ValueError – If sides is outside 3..7 or order < 1.

geometor.nicomachus.figurate_gnomons.construct_nicomachus_cubes_model(order: int = 4) → NicomachusCubesResult¶

Build an exact Model proving \(\sum_{k=1}^n k^3 = T_n^2\) (II.20).

Pairs Nicomachus’s odd-number block partition (\(1 = 1^3,\; 3 + 5 = 2^3,\; 7 + 9 + 11 = 3^3, \dots\)) with the exact L-gnomon square dissection of \([0, T_n]^2\) at triangular coordinates \(T_k = k(k + 1) / 2\), verifying symbolically that the k-th gnomon polygon has area \(T_k^2 - T_{k-1}^2 = k^3\).

Parameters:

order – Highest integer n >= 1 (default 4, where \(T_4 = 10\) and \(1 + 8 + 27 + 64 = 100\)).

Returns:

Verified NicomachusCubesResult.

Raises:

ValueError – If order < 1.
